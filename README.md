# Stashwise

Stashwise - אפליקציה פרטית לניהול תקציב חודשי ולחיסכון. רואים כמה נשאר להוציא החודש, כמה אפשר להוציא היום ובשבוע, כמה הולך לחיסכון, מה ההוצאות הקבועות, ואיך מתחלק הכסף בין הקטגוריות.

A private, encrypted, offline monthly-budget web app (Hebrew, RTL). No account, no server, no tracking.

## מה יש בה

- **בית** - "נשאר להוציא החודש", סכום ליום ולשבוע, סימון אם הקצב בסדר, תחזית לסוף החודש, חלוקת ההכנסה, תקציב לפי קטגוריה, לאן הלך הכסף, חצי שנה אחרונה ויעדי חיסכון.
- **תנועות** - כל התנועות של החודש, חיפוש וסינון, עריכה ומחיקה.
- **הוספה** - כל הדרכים קורות רק על המכשיר:
  - **צילומי מסך** מאפליקציית האשראי - אחד או כמה יחד, או "שיתוף" ישיר מהגלריה באנדרואיד. מנוע Tesseract רץ בתוך הדפדפן וקורא תאריך, שעה, בית עסק, מקום, סכום ותשלומים.
  - קובץ אקסל או CSV שהורדת מאתר ישראכרט או מאתר הבנק.
  - טקסט שהעתקת מצילום מסך, או הוספה ידנית.
  
  לפני שמירה מוצג מסך בדיקה: כפילויות מסומנות וכבויות, תשלום חשבון האשראי מהבנק מסומן "לא נספר", הוצאות קבועות מזוהות, והקטגוריה שבחרת לבית עסק נזכרת לפעם הבאה.
- **תקציב** - הכנסה, יום תחילת חודש, הוצאות קבועות, חיסכון (אחוז או סכום) ויעדי חיסכון, תקציב לכל קטגוריה וחלוקה אוטומטית.
- **עוד** - התקנה בטלפון, נעילה אוטומטית, החלפת קוד, גיבוי מוצפן ושחזור, מחיקת הכל.

## אבטחה ופרטיות

| מה | איך |
|---|---|
| הצפנה | כל הנתונים מוצפנים ב-AES-GCM 256. מפתח ההצפנה עטוף במפתח שנגזר מהקוד שלך (PBKDF2-SHA256, 600,000 סבבים). |
| איפה הנתונים | רק במכשיר, ב-IndexedDB של הדפדפן. אין שרת, אין חשבון, אין סנכרון. |
| חסימת רשת | מדיניות CSP חוסמת כל טעינה או שליחה לאתר אחר. האפליקציה לא יכולה לשלוח את הנתונים לשום מקום. |
| ניחוש קוד | אחרי 5 ניסיונות שגויים יש המתנה שגדלה בכל ניסיון. |
| נעילה | נעילה אוטומטית אחרי זמן ללא שימוש, ואחרי דקה ברקע. בנעילה הזיכרון מתנקה. |
| עדכונים | גרסה חדשה לא נכנסת לבד - מופיעה הודעה והמשתמש מאשר. |
| בנק ואשראי | האפליקציה לא מבקשת ולא שומרת סיסמאות של בנק או אשראי. |
| צילומי מסך | נקראים על המכשיר בלבד. מספרי כרטיס, תוקף, CVV, ת"ז, מספרי אישור ושורות מסגרת/יתרה נמחקים מהטקסט לפני הניתוח. התמונה והטקסט הגולמי נזרקים מהזיכרון מיד בסיום, והם לא נשמרים לעולם. |
| כפילויות | עסקה שכבר נשמרה, או שמופיעה בכמה צילומים חופפים, מסוננת אוטומטית (השוואה לפי תאריך, סכום, שעה ושם דומה). |

**אין שחזור קוד.** מי ששוכח את הקוד מאבד את הנתונים, אלא אם יש לו קובץ גיבוי.

### למה אין חיבור ישיר לבנק?
בישראל, גישה אוטומטית לנתוני בנק ואשראי של לקוחות (בנקאות פתוחה) מותרת רק לגופים בעלי רישיון לפי חוק שירות מידע פיננסי. אפליקציה פרטית בלי רישיון לא יכולה להתחבר לממשקים האלה. החלופה של "גירוד" אתרים דורשת לשמור את סיסמת הבנק בתוך האפליקציה - וזה בדיוק מה ששפע נמנעת ממנו. לכן הדרך הבטוחה היא להוריד את קובץ האקסל מהאתר ולטעון אותו.

## הרצה מקומית

אין תלות בשום ספרייה ואין שלב בנייה. צריך רק שרת קבצים סטטי:

```
python -m http.server 8080
```

ואז לפתוח `http://localhost:8080`. קריאת צילומי מסך פועלת באתר המפורסם בלבד, כי קבצי המנוע מתווספים בזמן הפרסום (`.github/workflows/pages.yml`). בדיקות הלוגיקה: `node tests/calc.test.mjs`.

## פרסום

כל שירות אחסון סטטי עם HTTPS מתאים (GitHub Pages, Cloudflare Pages, Netlify). האתר עצמו לא מכיל שום נתון של אף משתמש - כל משתמש שומר את הנתונים שלו אצלו, מוצפנים. כדי שאיש לא יוכל להחליף את הקוד באתר, כדאי להפעיל אימות דו-שלבי בחשבון האחסון.
